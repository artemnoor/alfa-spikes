# SENTiVENT Raw WebAnno Export

This folder contains the raw WebAnno/UIMA XMI source annotation bundle used to build the public SENTiVENT dataset artifacts. Source annotator identifiers in paths and file content are replaced with stable placeholders.
Binary CAS serialization files and project metadata are excluded from this source bundle because they are not safely anonymizable text annotation files.
